# ffmpeg-tui

一个用于 FFmpeg 的终端用户界面（TUI）。当前版本：**beta1.1**。

## 功能（beta1.1）

- 标签页式界面：`[文件]` `[视频]` `[音频]` `[任务]` `[设置]`，选中标签白色背景高亮
- 底部按键提示：`A/D：切换    方向键：选择`（文件页额外显示 `Delete：移除`）
- 鼠标**单击**标签栏切换页面（按下即切换）
- **文件页**：
  - 文件列表初始为空，`[添加文件]` 添加（输入路径 / 系统文件选择器），`Delete` 移除
  - 添加后自动调用 **ffprobe**（Windows 为 ffprobe.exe）读取并显示文件信息
  - **输出目录**选项：默认与输入文件相同；可手动输入；`$file` 表示输入文件所在目录，
    输入文件在不同目录时分别输出到与之对应的目录
  - 底部操作栏：`[添加文件]` `[设置输出容器]`，右下角显示 `输出容器：容器名`
- **视频页**（选项以 [FFmpeg 官方文档](https://ffmpeg.org/documentation.html) 为准）：
  - **编码器/解码器列表**：直接通过 `ffmpeg -encoders` / `ffmpeg -decoders` 获取
    （只含视频/音频，不依赖外部文件）
  - **编码器详情**：通过 `ffmpeg -h encoder=名称` 获取（描述、支持的像素格式、
    选项），据此判断是否支持预设与质量值
  - **编/解码器选择支持搜索**：在选项对话框中按 `/` 打开搜索框，输入关键字过滤列表
  - 编码：解码器（可以为空）、编码器（默认复制流，从动态列表选择具体编码器）、预设（视编码器而定，如 libx264 的 slow）
  - 质量：控制方式（恒定质量 CRF / 可变码率 VBR / 固定码率 CBR）、质量值（不支持质量值的编码器显示"编码器不支持"）、基础/最高/最低比特率（kbps）
  - 画面：分辨率（宽度与高度两个输入框）、帧率
- **音频页**：
  - 编码器（默认复制流：AAC/MP3/FLAC/Opus/Vorbis/WAV）、比特率、采样率
  - 位深度：对所有音频编码器可用，通过 `-sample_fmt s[位深]` 指定
    （如 `ffmpeg -i in.mp3 -sample_fmt s16 out.flac`；WAV/PCM 编码器同时
    与编码器名称同步：16→pcm_s16le、24→pcm_s24le…）
- **任务页（真实转码）**：
  - `[添加任务]` 把文件页的文件生成为转码任务（`ffmpeg` 命令由当前配置生成，
    含解码器/编码器/预设/质量/比特率/分辨率/帧率/音频编码/采样率）
  - `[开始]` 串行执行任务，解析 `ffmpeg` 进度输出实时显示百分比；
    命令按输入文件的流类型生成（纯音频输入不会错误附加 `-c:v`），
    失败时显示 ffmpeg 错误摘要
  - 输出命名与目录遵循设置页规则：添加时间 `[文件名]_YYYY-M-D-hhmmss`
    （字母个数表示补零位数）/ 指定后缀 / 不添加后缀；输出目录默认与输入文件
    相同（`$file` 表示输入文件所在目录，不同目录分别输出到对应目录）；
    扩展名为文件页设置的输出容器
- **设置页**：
  - 输出选项：添加时间（默认）/ 添加指定后缀 / 不添加后缀
  - 导出配置（JSON 文件）、加载配置、指定默认配置（启动时自动加载）
- **鼠标滚轮**：滚轮在标签栏切换标签、在列表中滚动选择选项
- **输入对话框**：`↑`/`↓` 在输入框与 `[确定]` `[取消]` 之间切换焦点
- 模态对话框（`┌┤ 标题 ├┐` 样式）、横向选项左右键切换、Tab/Shift-Tab 焦点循环

## 技术选型

使用 **Go** 编写，理由：

- 编译为单一静态可执行文件，**无需安装任何运行时**（满足跨平台分发要求）
- 原生支持 Windows / Linux 交叉编译（纯 Go，无 cgo）
- 终端 UI 基于 [tview](https://github.com/rivo/tview)（纯 Go，跨平台处理终端原始模式、颜色、鼠标）

## 构建

两种方式任选其一：

### 方式一：本地构建（需安装 Go 工具链，要求 Go 1.24+）

- Linux/macOS：`./build.sh`
- Windows：`build.bat`

### 方式二：容器构建（推荐，本仓库约定）

见 `../ffmpeg-tui-container/`，通过 podman（rootless）在容器中构建，
生成物输出到 `bin/` 目录。

两个脚本都会生成：

| 平台 | 产物 |
| --- | --- |
| Linux | `bin/ffmpeg-tui` |
| Windows | `bin/ffmpeg-tui.exe` |

## 运行

```bash
# Linux
./bin/ffmpeg-tui

# Windows（cmd 或 PowerShell）
bin\ffmpeg-tui.exe
```

## 按键

| 按键 | 功能 |
| --- | --- |
| `A` / `D` | 切换标签页 |
| `↑` / `↓` | 在当前页面的列表中选择项目 |
| `←` / `→` | 在横向排列的选项间切换焦点（文件页底部按钮、对话框 `[确定]`/`[取消]`） |
| `Tab` / `Shift-Tab` | 文件页：列表 ↔ 输出目录 ↔ `[添加文件]` ↔ `[设置输出容器]`；对话框内：切换焦点 |
| `Delete` | 文件页：移除当前选中的文件（按键提示仅在文件页显示） |
| `Enter` | 激活按钮 / 确认对话框（输入框内确认） |
| `Esc` | 关闭对话框；无对话框时退出 |
| `Q` / `Ctrl+C` | 退出 |

## 目录结构

```
ffmpeg-tui/
├── main.go          # 入口
├── ui/
│   ├── app.go       # 界面组装：标签栏 / 内容区 / 底部提示 / 按键与鼠标
│   ├── pages.go     # 文件页（输出目录 + 文件列表 + 操作栏）与任务页
│   ├── videopage.go # 视频页选项（编码 / 质量 / 画面）
│   ├── audiopage.go # 音频页选项（编码器 / 比特率 / 采样率 / 位深度）
│   ├── settingspage.go # 设置页（输出选项 / 配置导入导出）
│   ├── dialog.go    # 模态对话框（选项/输入/提示）+ 系统文件选择器
│   ├── config.go    # 配置模型 / JSON 导入导出 / 时间戳命名 / $file 输出目录
│   ├── encoders.go  # 编码器/解码器动态加载 + ffmpeg -h 详情解析
│   ├── command.go   # ffmpeg 命令生成与输出路径规则
│   └── task.go      # 任务模型 / 执行 / 进度解析
├── build.sh         # Linux 构建脚本（含交叉编译 Windows）
├── build.bat        # Windows 构建脚本（含交叉编译 Linux）
└── README.md
```
