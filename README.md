# ffmpeg-tui

一个用于 FFmpeg 的终端用户界面（TUI）。当前版本：**beta0.2**。

## 功能（beta0.1）

- 标签页式界面：`[文件]` `[视频]` `[音频]` `[任务]` `[设置]`
- 当前选中的标签以 **白色背景** 高亮，作为光标指示
- 底部按键提示：`A/D：切换    方向键：选择`
- 鼠标**单击**标签栏切换页面（按下即切换；终端需支持鼠标事件）
- **文件页**：
  - 文件列表初始为空，通过 `[添加文件]` 添加；`Delete` 移除当前选中的文件（`Delete：移除` 按键提示仅在文件页底部显示）
  - 添加文件后自动调用 **ffprobe**（Windows 为 ffprobe.exe）读取文件信息并显示
    （编码 / 分辨率 / 帧率 / 音频 / 时长 / 大小，如 `H264 · 640×480 · 30 fps · AAC 44100Hz · 1ch · 00:03 · 47 KB`）
  - 页面底部操作栏（边框内、按键说明之上）：`[添加文件]` `[设置输出容器]`，右下角显示 `输出容器：容器名`
  - `[添加文件]` 提供 **输入路径** 与 **选择文件**（系统文件选择器：Linux zenity/kdialog、Windows PowerShell）两种方式
  - `[设置输出容器]` 从常见容器列表（mp4/mkv/avi/mov/webm/flv/ts/wmv）中选择
  - `Tab` 在 文件列表 / `[添加文件]` / `[设置输出容器]` 之间切换焦点
- **横向选项切换**：`←`/`→` 方向键在横向排列的选项中切换焦点——文件页列表聚焦时可直接进入底部按钮（`→` 选中 `[添加文件]`、`←` 选中 `[设置输出容器]`），按钮间左右切换，`↑`/`↓` 返回文件列表；对话框选项列表聚焦时 `→` 进入 `[确定]`、`←` 进入 `[取消]`，按钮间左右切换
- **模态对话框**（居中显示、单线边框、`┌┤ 标题 ├┐` 样式）：
  - 选项选择对话框：选项列表 + `[确定]` `[取消]`
  - 输入对话框：输入框 + `[确定]` `[取消]`（`Enter` 确认，`Esc`/`[取消]` 关闭）
  - 对话框内 `Tab`/`Shift-Tab` 循环切换焦点
- 本版本仅演示界面与交互，**不执行真实转码**

## 技术选型

使用 **Go** 编写，理由：

- 编译为单一静态可执行文件，**无需安装任何运行时**（满足跨平台分发要求）
- 原生支持 Windows / Linux 交叉编译（纯 Go，无 cgo）
- 终端 UI 基于 [tview](https://github.com/rivo/tview)（纯 Go，跨平台处理终端原始模式、颜色、鼠标）

## 构建

两种方式任选其一：

### 方式一：本地构建（需安装 Go 工具链，要求 Go 1.24+）

- Linux/macOS：`./build.sh`
- Windows：`build.bat`

### 方式二：容器构建（推荐，本仓库约定）

见 `../ffmpeg-tui-container/`，通过 podman（rootless）在容器中构建，
生成物输出到 `bin/` 目录。

两个脚本都会生成：

| 平台 | 产物 |
| --- | --- |
| Linux | `bin/ffmpeg-tui` |
| Windows | `bin/ffmpeg-tui.exe` |

## 运行

```bash
# Linux
./bin/ffmpeg-tui

# Windows（cmd 或 PowerShell）
bin\ffmpeg-tui.exe
```

## 按键

| 按键 | 功能 |
| --- | --- |
| `A` / `D` | 切换标签页 |
| `↑` / `↓` | 在当前页面的列表中选择项目 |
| `←` / `→` | 在横向排列的选项间切换焦点（文件页底部按钮、对话框 `[确定]`/`[取消]`） |
| `Tab` / `Shift-Tab` | 文件页：列表 ↔ `[添加文件]` ↔ `[设置输出容器]`；对话框内：切换焦点 |
| `Delete` | 文件页：移除当前选中的文件（按键提示仅在文件页显示） |
| `Enter` | 激活按钮 / 确认对话框（输入框内确认） |
| `Esc` | 关闭对话框；无对话框时退出 |
| `Q` / `Ctrl+C` | 退出 |

## 目录结构

```
ffmpeg-tui/
├── main.go          # 入口
├── ui/
│   ├── app.go       # 界面组装：标签栏 / 内容区 / 底部提示 / 按键与鼠标
│   ├── pages.go     # 五个标签页的内容（文件页含底部操作栏）
│   └── dialog.go    # 模态对话框（选项/输入/提示）+ 系统文件选择器
├── build.sh         # Linux 构建脚本（含交叉编译 Windows）
├── build.bat        # Windows 构建脚本（含交叉编译 Linux）
└── README.md
```
